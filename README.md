# Warriors Karate Academy

Static website for Warriors Karate Academy, Kahrai, Agra. Hosted at https://karate-india-academy.vercel.app/ using the existing project.

Business name, address, phone, daily opening hours, 4.7 rating and 25 reviews verified on 31 October 2026 from https://maps.app.goo.gl/TP63cDb7t8UueRSQ8. Gallery and hero images were downloaded from that listing. Review quotes reproduce the visible listing. Class schedules and fees must be confirmed with the academy. WhatsApp enquiry prepares a message for the listed business phone; the visitor reviews and sends it.

Visual update: original SVG W / belt / open-circle emblem. Hero stock footage: Artem Podrez, https://www.pexels.com/video/guys-doing-karate-6263394/ under https://www.pexels.com/license/. UHD for desktop; Full HD for small screens. Illustrative stock is labeled, separate from genuine academy gallery photos. Video is muted, pausable, suspended outside the hero and disabled by default for reduced motion or data saving.
